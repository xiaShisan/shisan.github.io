# shisan.github.io

This repository hosts the static files for the **shisan.github.io** personal blog. The site is generated using [Gridea](https://gridea.dev/), a desktop app for managing and publishing static blogs.

## Build Instructions

1. Install the Gridea application on your computer.
2. Open your blog project in Gridea and create or edit posts.
3. Click **Publish** to generate the static site. Gridea places the files in a folder named `public`.

## Publish to GitHub Pages

1. Clone this repository or pull the latest changes.
2. Replace the current contents with the files from the `public` directory.
3. Commit and push the updates to the `master` (or `main`) branch.
4. GitHub Pages will automatically serve the site at `https://shisan.github.io/`.
